*وثيقة مهام ووظائف دور الطالب - من الألف إلى الياء*

يحتوي دور الطالب على 5 أنظمة رئيسية:
1.  الجداول والمواعيد
2.  تسجيل الحضور
3.  الدردشات
4.  الدفعات المالية
5.  مستودع الملفات

*1. الجداول والمواعيد*

*A. عرض الجدول:*
- يظهر الجدول بنفس تصميم نظام المحاضر
- زر اختيار نطاق العرض: يوم / أسبوع / شهر
- الجدول يحتوي على بطاقات الأحداث

*B. بطاقات الأحداث:*
أنواع الأحداث هي: محاضرة، سمنار، معمل، بحث، واجب

*كل بطاقة تعرض:*
- اسم الحدث ونوعه
- المادة والمحاضر
- عنوان الحدث
- الملفات المرتبطة والملاحظات

*1. الثلاثة الأولى (محاضرة، سمنار، معمل) تتميز بـ:*
- زمن ومكان الانعقاد
- لوحة تسجيل الحضور

*2. الاثنان الباقيان (بحث، واجب) يتميزان بـ:*
- موعد نهائي للتسليم
- مكان التسليم

*2. تسجيل الحضور*

تظهر لوحة تسجيل الحضور ضمن بطاقات الأحداث التي تتطلب حضور وهي: محاضرات، سمنارات، معامل.

*نافذة تسجيل الحضور تتكون من 3 أزرار:*

*A. زر مساعدة زملائي في تسجيل الحضور:*
هذا الزر للطالبين المسؤولين عن جمع الحضور.

- *في حال التسجيل بالبلوتوث:*
    1.  يعرض باركود في الشاشة ليمسحه المحاضر
    2.  يعرض شاشة البث المباشر لقائمة تسجيل الحضور
    3.  يعرض شاشة شكراً بعد اكتمال العملية

- *نافذة البث المباشر تحتوي على:*
    1.  خانة بحث عن الطلاب
    2.  زر تحديث الصفحة
    3.  قائمة الطلاب لحظة بلحظة (اسم الطالب + رمز الـ ID)

- *في حال التسجيل عبر الـ QR Code:*
    1.  بعد مسح باركود المحاضر يظهر زر "بدء التسجيل"
    2.  تقسم الشاشة إلى قسمين: النصف العلوي كاميرا لمسح الباركود، النصف السفلي قائمة البث المباشر
    - مدة التسجيل بالباركود يحددها المحاضر

*B. زر تسجيل الحضور باستخدام البلوتوث:*
يتغير نص الزر حسب الحالة:
- قبل فتح الباب: "بانتظار بدء التسجيل"
- عند بدء التسجيل: "تسجيل الحضور خلال X ثانية"
- عند إرسال الإشارة: "جاري التسجيل"
- عند النجاح: "تم التسجيل"
- عند الفشل: "جاري إعادة المحاولة" (يحاول 3 مرات، وتظهر نافذة منبثقة توضح سبب الفشل)

*C. زر تسجيل الحضور باستخدام الباركود:*
- يعرض الباركود الخاص بالطالب في الشاشة ليمسحه الطالب المسؤول
- تظهر رسالة "تم التسجيل" عند النجاح

*3. نظام الدردشات*

*A. أنواع الدردشة:*
1.  *قنوات المواد الدراسية:* قناة لكل مادة مسجل بها الطالب (نفس نظام قنوات المحاضر - شبيهة بقنوات تلغرام)، يمكنه قراءة منشورات المحاضر والتفاعل والتعليق عليها
2.  *الدعم الفني:* دردشة مباشرة مع الإداريين للاستفسارات وحل المشاكل
3.  *الدردشات الداخلية (اختياري):* بين الطلاب في نفس الدفعة

*B. قوائم الدردشات:*
- قائمة بالقنوات والدردشات السابقة مرتبة حسب آخر رسالة
- لكل خيار صورة واسم وآخر رسالة ووقتها
- خانة بحث عن مادة أو محاضر

*C. صفحات الدردشة:*
1.  *صفحة قناة المادة:*
    - عرض المنشورات السابقة للمحاضر مرتبة من الأحدث للأقدم
    - كل منشور يحتوي على: النص، الوسائط المتعددة، التفاعلات، عدد التعليقات
    - خانة التعليق والتفاعل
2.  *صفحة الدعم الفني والدردشة الداخلية:*
    - الرسائل وتاريخ إرسالها (مرسلة / مستلمة / مقروءة)
    - صندوق إدخال نص وإضافة ملفات وصور

*4. نظام الدفعات المالية (بعد التعديل)*

*A. لوحة الحالة المالية:*
- عرض حالة الحساب: مدفوع بالكامل / جزئي / غير مدفوع
- إجمالي الرسوم الدراسية ورسوم التسجيل
- المبلغ المتبقي والمبلغ المدفوع
- شريط تقدم لنسبة التحصيل

*B. عرض معلومات الحساب حسب بوابة الدفع - _النظام الجديد_:*
- عند الضغط على زر "إضافة دفعة جديدة" تظهر أولاً قائمة بوابات الدفع المتاحة
- عند اختيار بوابة دفع معينة، تظهر نافذة منبثقة تعرض معلومات الحساب الخاصة بتلك البوابة تلقائياً، وتتضمن:
    1.  اسم البوابة وشعارها (مثال: بنكك، فوري، بنك الخرطوم، كاش)
    2.  رقم الحساب / رقم الموبايل / الـ IBAN المخصص للدفع
    3.  اسم صاحب الحساب (الجامعة)
    4.  تعليمات التحويل الخاصة بتلك البوابة
    5.  زر نسخ رقم الحساب
    6.  زر "لقد قمت بالتحويل" للانتقال لخطوة رفع الإشعار
- _يتم جلب هذه المعلومات ديناميكياً من إعدادات الإداري في نظام الدفعات المالية، ويمكن للإداري تعديلها لكل بوابة_

*C. سجل المعاملات:*
- قائمة بكل المعاملات من الأحدث للأقدم
- كل معاملة تعرض: رقم المعرف، المبلغ، بوابة الدفع المستخدمة، الحالة (مقبول / مبدئي / مرفوض / قيد المراجعة)، التاريخ
- زر عرض التفاصيل (نافذة منبثقة): صورة إشعار الدفع، الملاحظات، الإيصال

*D. إضافة دفعة جديدة:*
- زر بارز "إضافة دفعة جديدة"
- *الخطوات:*
    1.  اختيار بوابة الدفع -> عرض معلومات حساب تلك البوابة
    2.  إدخال المبلغ المحول
    3.  رفع صورة إشعار الدفع الواضحة
    4.  خانة ملاحظات اختيارية (رقم العملية / اسم المحول)
    5.  زر تأكيد وإرسال
- بعد الإرسال يظهر تنبيه: "تم إرسال طلبك بنجاح وهو قيد المراجعة المبدئية"
"
*5. مستودع الملفات*

*A. عرض الملفات:*
- مقسم حسب المواد الدراسية المسجل بها الطالب
- داخل كل مادة، الملفات مقسمة إلى 6 فئات (نفس تقسيم المحاضر):
    1.  ملفات المحاضرات (الشيتات)
    2.  التسجيلات الصوتية للمحاضرات
    3.  ملفات إضافية للمحاضرات
    4.  الكتب والمراجع
    5.  روابط قنوات اليوتيوب
    6.  اختبارات وأسئلة سابقة
- الثلاثة الأولى مرتبطة بحدث محاضرة في الجدول، البقية عامة للمادة

*B. بطاقة الملف:*
- اسم الملف ونوعه وأيقونته
- وصف الملف وتاريخ رفعه واسم المحاضر
- زر فتح / تحميل / مشاهدة

*C. أدوات الطالب:*
- خانة بحث عام في كل الملفات (بالاسم أو المادة)
- فلترة حسب المادة ونوع المحتوى وتاريخ الرفع
- زر تنزيل جماعي لملفات محاضرة معينة
- إمكانية وضع علامة "مفضل" على الملفات المهمة
