### *وثيقة واجهات الإداري - من الألف إلى الياء*

*أنواع الإداري:*
1.  *الإداري الرئيسي:* له سيطرة كاملة على نظام جامعته
2.  *الإداري الفرعي:* له سيطرة محدودة يحددها الإداري الرئيسي

*لوحات التحكم الرئيسية (6 لوحات):*
1.  الإدارة العامة
2.  إدارة المنشآت التعليمية
3.  الدردشات
4.  نظام الدفعات المالية
5.  إدارة جلسات الامتحانات
6.  لوحة التحكم الرئيسية

---

### *1. الإدارة العامة*

تحتوي على 5 لوحات:

#### *1.1 البرامج الأكاديمية*
- عرض البرامج على شكل نوافذ مستطيلة مقسمة إلى: دبلوم، بكالوريوس، ماجستير
- كل برنامج يحتوي على دفع دراسية مسماة بسنة دخولها
- *إضافة برنامج جديد (نافذة منبثقة):*
    1.  معلومات البرنامج: اسم البرنامج، تصنيفه (دبلوم، بكالوريوس، دكتوراه)، عدد الفصول
    2.  نبذة تعريفية: حقل نصي فارغ
    3.  المواد الدراسية:
        - عرض المواد الموجودة لكل فصل مع خانة تحديد الفصل
        - كل مادة تعرض كمستطيل: اسم المادة، الساعات النظرية والعملية والمعتمدة
        - خانة إضافة مادة جديدة: اسم المادة، الساعات النظرية، العملية، المعتمدة
- إمكانية تعديل وحذف البرامج والمواد
- زر إضافة دفعة دراسية جديدة

#### *1.2 إدارة الدفعات الدراسية*
- عرض كل الدفعات مقسمة حسب البرامج الأكاديمية، كل برنامج وتحته الدفعات كأزرار
- الضغط على دفعة يقود لإدارتها
- *إضافة دفعة جديدة (نافذة منبثقة):* اسم الدفعة بسنة الدخول، البرنامج، الفصل الحالي، الرسوم الدراسية، رسوم التسجيل، نسبة القبول
- يمكن التعديل والحذف

*داخل إدارة الدفعة (3 لوحات تحكم):*

*أ- لوحة إدارة الطلاب:*
- خانة بحث (الاسم، الرقم الجامعي، ID)
- قائمة الطلاب مرتبة أبجدياً + خانة إضافة طالب جديد
- *نافذة بيانات الطالب:*
    - معلومات أساسية: الاسم، تاريخ الميلاد، مكان النشأة، نسبة التحصيل السابقة، البرنامج والدفعة + صور الوثائق (إثبات هوية، شهادة سابقة، كشف طبي) مع زر رفع وزر طلب رفع
    - معلومات اتصال: هاتف 1 و 2، هاتف ولي أمر 1 و 2، البريد الجامعي
    - معلومات حالة الدفع: حالة الحساب، باقي الرسوم، عرض آخر 5 دفعات + زر عرض السجل كامل
- إمكانية حذف وتعديل بيانات الطالب أو حذف الحساب، وتغيير انتمائه للبرنامج والدفعة

*ب- لوحة إدارة الفصول الدراسية (4 مراحل تظهر كخطوات أعلى الشاشة):*

*1. مرحلة الخمول:* شاشة فارغة مع زر "بدء التحضير لفصل جديد" في المنتصف + خانة رفع إعلان مخصص للدفعة ومحاضريها

*2. مرحلة التحضير:* تبدأ بعد الضغط على بدء فصل جديد
- لوحة المواد الدراسية لهذا الفصل: كل مادة مع معلوماتها (الساعات) + المحاضرين المرتبطين بها + أزرار: طلب تحديد جدول، طلب تحديد موازين، مراسلة
- زر ربط محاضر بالمواد التي بلا محاضر (قائمة منبثقة بأسماء المحاضرين)
- خانة رفع إعلان + زر الانتقال للمرحلة التالية وبدء الفصل

*3. مرحلة الدراسة:*
- الجدول الأسبوعي المصغر مع تنقل بين الأسابيع، متوسط المحاضرات/الأسبوع، متوسط أيام العمل، نسب الحضور والغياب
- لوحة المواد + أزرار: طلب تحديد بنك أسئلة، طلب موازين، مراسلة
- *زر بدء امتحان (نافذة منبثقة):* نوع الامتحان (أونلاين/ورقي/معمل)، نهائي أم نصفي، الهدف (جمع درجات/قياس قدرات)، المادة ووقت الامتحان، الزمن والمكان (نوافذ حجز الوقت والمنشآت)، عدد حسابات المراقبين وكلمات الدخول
    - ملاحظات: وظيفة المراقبين للأونلاين فقط، في المعمل تتحول لمدخلي درجات وتلغى وظيفة الوقت، الأونلاين يشترط بنك أسئلة، الحضور بالباركود فقط، لا يبدأ الأونلاين إلا بعد تأكيد الأسئلة، لا يجمع النتائج إلا بعد ضغط زر الجمع
- *لوحة امتحانات الملحق:* تظهر تلقائياً لكل مادة لم يتساوى عدد الجالسين مع عدد الطلاب، بطاقة الامتحان + زر عرض الطلاب المطلوبين + زر إكمال الإعداد (يعرض بيانات الامتحان الأصلي مظللة ما عدا الزمن والمنشأة وحسابات المراقبين)
- *عرض الامتحانات:* التي تم الجلوس لها مع أزرار: جمع الدرجات، طلب رفع الدرجات، نشر الدرجات (عام/مخصص)، معاينة الدرجات، معاينة ومشاركة الإحصائيات
- *عرض الامتحانات القادمة:* مع زر عرض التفاصيل
- *عرض إحصائيات المادة:* متوسط الدرجات، الانحراف المعياري، أعلى وأدنى درجة، نسبة نجاح ورسوب، توزيع الدرجات، نسب التقديرات (A...F)، عدد الراسبين القريبين من النجاح، عدد المحرومين والمنسحبين

*4. مرحلة النتائج والأرشفة:*
- عرض كل الامتحانات التي تم الجلوس لها وعدد المواد التي لم يمتحن فيها، مع كل أزرار الامتحان السابقة + زر بارز لجمع النتائج
- _لا تجمع النتائج إلا بعد جلوس امتحان لكل مادة وإكمال كل مدخلات الأوزان_
- *النتائج والإحصائيات:* معدل النجاح العام، نسبة الرسوب، جدول معدلات النجاح وأعلى وأدنى الدرجات، توزيع معدلات الطلاب، أكثر الفئات شيوعاً، متوسط المعدل التراكمي، نسبة المتفوقين/الراسبين، زر عرض إحصائيات كل مادة، عرض أعمال السنة (جدول درجات الواجبات والبحوث والسمنارات والحضور)، طلب طباعة تقرير
- *أرشفة البيانات:* تتم تلقائياً بعد شهر من النتائج، تشمل: بيانات الطلاب المشاركين (وثائق وصور)، تفاصيل كل مادة ومحاضرها، جميع الملفات الدراسية (شيتات ومراجع وتسجيلات - لا تشمل الفيديوهات)، سجلات الحضور، إجابات الأونلاين، نتائج الامتحانات والواجبات. بعد الأرشفة يطلب من الإداري تنزيل النسخة الخارجية.

#### *1.3 إدارة حسابات المحاضرين*
- خانة بحث عن حساب
- خانة إضافة حساب (نافذة منبثقة): اسم المحاضر، نبذة تعريفية، هاتف 1 و 2، بريد تسجيل الدخول
- بطاقات المحاضرين (صورهم وأسماؤهم)

#### *1.4 طلبات تأكيد صلاحية المستندات*
- خانة بحث بمعرف الطلب
- بطاقات الطلبات من الأقدم للأحدث + زر عرض التفاصيل
- *نافذة التفاصيل:* نافذة بيانات الطالب + صورة المستند المرفوع واضحة للمقارنة + أزرار تأكيد/رفض

#### *1.5 إدارة الأرشيف*
- متصفح ملفات بالترتيب: البرنامج < الدفعة < الفصل الدراسي
- كل فصل ملف مضغوط بكلمة سر عشوائية محفوظة في الخادم، يفتح أونلاين فقط
- *المحتويات:*
    - *A. بيانات توزيع الدرجات:* سجل الحضور، درجات أعمال السنة، درجات الامتحانات
    - *B. بيانات مالية:* سجل الدفعات، صور إشعارات الدفع، إيصالات
- للقراءة فقط، بيانات الطلاب وأوراقهم في مجلد الدفعة خارج مجلد الفصل لتفادي التكرار

### *2. إدارة المنشآت التعليمية*

لوحة واحدة مدمجة تحتوي على 3 أقسام:

*A. جدول حجوزات المنشآت:*
- زر تحديد المنشأة، جدول أسبوعي من 7 صباحاً لـ 7 مساءً، أزرار تنقل بين الأسابيع، بطاقات الأحداث (نوع الحدث وعنوانه + زر تفاصيل)
- *تفاصيل البطاقة (نافذة منبثقة):* نوع الحدث، العنوان، الوصف، المكان، الزمن، الملفات المرفقة، زر إلغاء الحجز

*B. إدارة المنشآت التعليمية:*
- زر إضافة منشأة (نافذة منبثقة): اسم المنشأة، نوعها (قاعة/معمل)، حجمها، السعة الاستيعابية، نبذة تعريفية
- قائمة المنشآت: اسم كل منشأة، هل محجوزة الآن، زر تعديل

*C. قائمة طلبات الحجز:*
- كل طلب: اسم المحاضر، زمن الحجز، زر عرض التفاصيل
- *نافذة التفاصيل:* اسم المحاضر، المادة، الدفعة، عدد الطلاب، وقت الحجز، عدد الحجوزات المطلوب
- تتكرر الخطوات حسب عدد الحجوزات: زر تنقل بين المنشآت المقترحة، جدول المنشأة المختارة، زر حجز المنشأة، ثم زر تأكيد الحجز
- الاقتراح بناءً على أوقات الفراغ والسعة

### *3. الدردشات*

*A. الأنواع:* دردشات داخلية (مع المحاضرين والإداريين)، دعم فني (مع الطلاب) - نفس الوظائف باختلاف الطرف الآخر
*B. قوائم الدردشة:* قائمة الدردشات السابقة (صورة واسم)، زر إضافة دردشة جديدة، عرض حسابات المحاضرين/الإداريين في الداخلية، خانة بحث بمعرف الطالب في الدعم الفني
*C. صفحة الدردشة:* الرسائل وتاريخها، صندوق إدخال نص وإضافة ملفات

### *4. نظام المدفوعات المالية*

*A. الإحصائيات:*
1.  إحصائيات مالية سريعة: إيرادات اليوم/الشهر، إجمالي الإيرادات من كل بوابة، عدد طلبات التأكيد المبدئي والنهائي
2.  إحصائيات الطلاب: عدد الدافعين بالكامل/جزئي/لم يدفعوا، ونسبتها لكل برنامج + زر عرض الطلاب
3.  إحصائيات طرق الدفع: توزيع الدفعات، متوسط زمن التأكيد، عدد ونسبة المقبول/المرفوض، الطلاب المشبوهين
4.  تصدير كـ PDF / Excel

*B. لوحة طلبات التأكيد المبدئي:*
1.  بحث بمعرف الطلب
2.  فلترة: الزمن (أحدث/أقدم/تاريخ معين)، بوابة الدفع، دفعة دراسية
3.  قائمة الطلبات (أحدث لأقدم): رقم المعرف، المبلغ، البوابة، زر عرض التفاصيل
4.  *نافذة تفاصيل المعاملة:* بيانات الطالب الأساسية + وثائقه + معلومات الاتصال + حالة الدفع (حالة الحساب، الرسوم المتبقية، آخر 5 دفعات) + صورة إشعار الدفع + ملاحظات الطالب + خانة ملاحظات + زر تأكيد مبدئي/رفض
5.  زر إضافة معاملة كاش (نافذة منبثقة): تحديد البرنامج/الدفعة، بحث عن الطالب، عرض بياناته، إدخال المبلغ، تأكيد نهائي

*C. لوحة المراجعة النهائية (3 مراحل في صفحة واحدة + مذكرة جانبية ثابتة):*
1.  *المراجعة:* قائمة الطلبات المؤكدة مبدئياً (زر تحديد كمرفوض، معرف، مبلغ، بوابة، تفاصيل) - المرفوض ينتقل للمرحلة التالية
2.  *مراجعة الطلبات المرفوضة:* نفس القائمة للمعاملات المحددة فقط + طلب تأكيد للانتقال
3.  *التأكيد النهائي:* قائمتان (مقبولة ومرفوضة) + زر تأكيد نهائي وإرسال الإيصالات - تختفي بعدها من لوحة التأكيد وتبقى في السجل

*D. سجل المعاملات:* بحث بمعرف، فلترة (زمن/بوابة/دفعة)، قائمة المعاملات (حالة مقبول/مرفوض، معرف، مبلغ، بوابة، زر تفاصيل) بنفس نافذة التفاصيل السابقة

### *5. إدارة جلسات الامتحانات*

لوحة واحدة بثلاثة أزرار علوية:

*1. الامتحانات القادمة:* بطاقات الامتحانات المقبلة + زر عرض التفاصيل (غير قابلة للتعديل عدا زمن ومكان الحجز، عدد حسابات المراقبين، كلمات المرور)

*2. الامتحانات الجارية:* نفس القائمة + زر معاينة للأونلاين + زر إضافة طالب ذي حالة خاصة (كتابة كلمة المرور)
- *زر المعاينة يحتوي على:* قائمة الطلاب، قائمة تسجيل الحضور، قائمة من لم يسلم، قائمة من سلم، قائمة أصحاب الظروف الخاصة، مراقبة الغش
- كل حالة خاصة بجانبها زر دخول الامتحان، يدخل الطالب عبر هاتف المراقبين بكلمة دخول فريدة
- *مراقبة الغش:* قائمة الطلاب مع نسبة احتمالية الغش مرتبة من الأعلى للأدنى + زر إرسال تحذير

*3. الامتحانات المكتملة:* نفس قوائم القادمة + زر جمع الدرجات بدل التفاصيل، زر المعاينة بنفس تفاصيل الجارية + زر تأكيد حالة الغش (تسجيل رسوب مباشر)، لا تعرض النتائج هنا
